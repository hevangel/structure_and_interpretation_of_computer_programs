This is an incremental, checked-in learning project. **Not all textbook code or exercises have been converted.** Coverage status means a runnable *representative* implementation exists, not that every subsection or edition-specific variant is complete.

## Remaining work

Perform an edition-by-edition inventory of **every** example (including embedded snippets and distinct exercises) against the official books, assign identifiers with original section references, and write independent Rust analogues. Add tests that demonstrate the intended result and document semantic differences introduced by Rust. Only then may the project claim exhaustive coverage.

For source navigation and historical differences, consult [edition notes](docs/editions.md). For contribution requirements, consult [the porting guide](docs/porting-guide.md).
