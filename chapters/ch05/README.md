# Chapter 5: Computing with Register Machines

Move from high-level programs to an explicit machine with registers, stacks, memory, and compilation.

## A Rust perspective

These examples connect operational semantics to CPU and virtual-machine design: control flow, bytecode, and storage management are not magic.

## How to study

1. Read each numbered section introduction before inspecting source code.
2. Predict the program's output and resource usage.
3. Run the associated executable and its unit tests.
4. Modify one assumption and explain which invariant breaks.
