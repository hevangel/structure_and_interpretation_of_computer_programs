# Chapter 1: Building Abstractions with Procedures

Programs as compositions of small functions; evaluation models, recursion, iteration, and higher-order functions.

## A Rust perspective

Rust begins with ownership and explicit types rather than Scheme's dynamically typed values. We will use that difference to sharpen the distinction between a computation's *meaning* and its implementation.

## How to study

1. Read each numbered section introduction before inspecting source code.
2. Predict the program's output and resource usage.
3. Run the associated executable and its unit tests.
4. Modify one assumption and explain which invariant breaks.
