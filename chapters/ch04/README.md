# Chapter 4: Metalinguistic Abstraction

Build evaluators and domain-specific languages, then change the rules of evaluation.

## A Rust perspective

We construct small interpreters instead of translating Scheme's self-interpreters verbatim. Rust enums distinguish syntax from values and make invalid states harder to express.

## How to study

1. Read each numbered section introduction before inspecting source code.
2. Predict the program's output and resource usage.
3. Run the associated executable and its unit tests.
4. Modify one assumption and explain which invariant breaks.
