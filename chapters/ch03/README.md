# Chapter 3: Modularity, Objects, and State

How local mutation, time, concurrency, and delayed computation change a program's behavior.

## A Rust perspective

Rust's ownership and synchronization rules help make effects explicit, but stateful behavior still requires careful reasoning about history and order.

## How to study

1. Read each numbered section introduction before inspecting source code.
2. Predict the program's output and resource usage.
3. Run the associated executable and its unit tests.
4. Modify one assumption and explain which invariant breaks.
