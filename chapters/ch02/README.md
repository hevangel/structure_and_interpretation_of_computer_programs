# Chapter 2: Building Abstractions with Data

Representation independence, recursive data, symbolic computation, and generic arithmetic.

## A Rust perspective

Rust structs, enums, traits, and pattern matching make representation choices visible. The goal is to design interfaces that let clients ignore those choices.

## How to study

1. Read each numbered section introduction before inspecting source code.
2. Predict the program's output and resource usage.
3. Run the associated executable and its unit tests.
4. Modify one assumption and explain which invariant breaks.
